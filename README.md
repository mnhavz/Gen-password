# 🔐 Generador de Contraseñas en Python

Proyecto realizado en Python para generar contraseñas aleatorias.

## 📌 Descripción

Este programa genera una contraseña aleatoria utilizando:

- Letras minúsculas
- Letras mayúsculas
- Números
- Símbolos

La longitud de la contraseña generada actualmente es de 12 caracteres.

## 🛠️ Tecnologías utilizadas

- Python 3
- Módulo random

## ⚙️ Funcionamiento

El programa sigue estos pasos:

1. Define las letras minúsculas disponibles.
2. Convierte las letras a mayúsculas.
3. Define los números.
4. Define los símbolos.
5. Junta todos los caracteres disponibles.
6. Selecciona aleatoriamente 12 caracteres.
7. Une los caracteres para formar la contraseña.
8. Muestra la contraseña por pantalla.
